- [x] 2.2 Retire `DeliveryService`'s reviewer notification fan-out for approvals in favour of OpenRegister task notifications (Talk delivery stays until 2.3)
      - 2026-11-26: `ApprovalTaskNotice::notifiedAssignee()` names the reviewer OpenRegister already notifies through the mirror task: the approval carries `taskUuid`, is routed to one named user (the mirror is created assigned, and OpenRegister's `taskAssignedToYou` rule fires on `create`), and `OCA\OpenRegister\Listener\TaskNotificationListener` exists. `DeliveryService` raises no hermiq notification for exactly that user on every approval flavour (schedule, flow, webhook, skill draft, tool) and counts them as reached; other recipients of the round are still notified, and the Talk room post and Note-to-self stay until 2.3. Tests: `ApprovalTaskNoticeTest`, `DeliveryServiceApprovalTaskNoticeTest` (each fails with the guard removed).
- [x] 2.3 Repoint `TalkApprovalReactionListener` and `Talk/TalkApprovalBinding` onto the mirror task (a Talk reaction completes the TASK, so both surfaces converge on one decision path)
      - 2026-11-26: `TalkApprovalReactionListener` now decides through `TalkReactionDecider`: the reaction completes the mirror task as the reactor (`MirrorTaskCompletion`, `TaskService::completeWithAnswer()` with `approved`, or `rejected` plus the reaction's reason as the mandatory comment; a pool task is claimed for the reactor first), and OpenRegister's terminal event lets `TaskTerminalListener` apply the decision. The decider re-reads the approval and decides on hermiq's path only while it is still pending; an approval it cannot re-read is left alone, so a run is never released twice. No mirror, no task surface, or a refused completion and claim: hermiq decides directly, as before. `Talk/TalkApprovalBinding` stays keyed on the approval: it resolves the reacted message to the approval, which carries the mirror's `taskUuid`, and still records `decidedVia: reaction`. The reviewer check, the un-react rule and the room confirmation are unchanged. Tests: `MirrorTaskCompletionTest`, `TalkReactionDeciderTest`, the existing `TalkApprovalReactionListener*Test` on the fallback path.
