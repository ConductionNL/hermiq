The decision

One boundary keeps the fleet coherent

A source study proved OpenRegister already ships the agent engine — run loop, MCP tools, LLPhant/Ollama, and a hash‑chained audit trail. So Hermiq owns only scheduling and a richer agent‑management UX, and delegates everything else. This is the line to hold in docs, UI, and review.

Ground truth

Verified in the code — and what to watch

Already there (reused)

  • ✓AuditTrail ships a hash‑chained, tamper‑evident log with tenant scoping, GDPR Art.30 register, DSAR + verify() endpoints — AI‑Act record‑keeping is inherited.
  • ✓MCP + LLPhant + Ollama and AgentTool exist — the tool, provider and delegation layers are deleted, not ported.
  • ✓ObjectEntity carries owner / organisation / groups / version / locked / deleted — multi‑tenant RBAC and rollback come free.

Risks & dependencies

  • !Talk (spreed) isn’t installed on the instance (only opentalk video) — the primary channel is an operator dependency; falls back to OCS polling.
  • !Ollama/Qwen function‑calling fidelity is the main quality risk; the fleet OllamaChat.php think:false/keep_alive patch must be applied.
  • !Redaction must run before persist and every write must go through ObjectService — enforce both as a CI gate or the immutable log leaks or gaps.
  • !NC’s single TimedJob polls — sub‑5‑minute schedules need webcron/systemd.
